Aberta direto do arquivo, a galeria não lê o CSS (copiar e ver código ficam desligados) e a fonte não carrega. Abra pelo servidor: dê dois cliques em abrir-galeria.cmd na pasta do projeto.

como usar

  1. Pré-visualizar sem publicar. Dois cliques em preview-loja.cmd (ou preview-celular.cmd). Abre a loja num navegador à parte com este CSS aplicado; cada vez que o custom.css é salvo, a página atualiza. Um botão no canto liga e desliga o CSS para comparar com o tema original. A senha da loja é pedida só na primeira vez.
  2. Hospedar a fonte (uma vez). Suba a pasta fonts/ na Vercel (já tem o vercel.json com CORS liberado) e troque SEU-PROJETO no começo do CSS pelo endereço real.
  3. Publicar. Salve o custom.css, clique em copiar CSS completo e cole em Loja online › Layout › Editar layout › Configurações avançadas › CSS personalizado.

O arquivo nuvemshop/custom.css é a fonte da verdade; o painel é só destino. Ícones e formas são SVGs nas pastas icones/ e formas/: depois de trocar um desenho, rode npm run embutir em ferramentas/ para levá-lo ao CSS.

tipografia

Paintzoas (um peso só) é a identidade: títulos, botões, menu, preços, filtros. Helvetica Neue é a fonte complementar das partes burocráticas: descrições, formulários, frete, rodapé legal. Tamanhos de desktop; no celular os títulos encolhem.

Helvetica Neue entra onde o texto precisa ser lido com calma: a descrição da marca no rodapé, a descrição do produto, os campos de formulário e o frete. Ela já vem instalada em iPhone e Mac; no Windows e no Android a lista cai para Arial.

texto com negrito sintético do navegador

A Paintzoas é unicase: o "i" minúsculo tem pingo e as outras minúsculas parecem maiúsculas. Por isso nada força caixa alta. A fonte veio com alguns caracteres sem desenho. Na versão web (Paintzoas.woff2), â ó ô õ ú minúsculas usam o desenho da maiúscula, e símbolos como ( ) / + * ° ª º aparecem na Helvetica. Vale desenhar esses caracteres na fonte original.

botões

Botão primário "tosquinho": desenho traçado do original, fatiado para esticar com qualquer texto sem deformar os cantos. Funciona em link, botão e campo de envio (o "Comprar" do produto). O hover desenha o contorno rosado fora da caixa, sem empurrar nada.

Para mudar o tamanho, mexa só em --u (1 pixel do desenho). Abaixo de 1px os degraus dos cantos ficam menores que um pixel da tela e arredondam um pouco; é esperado no médio e no pequeno. Contorno do hover é cortado onde algum elemento pai esconde o que vaza (overflow: hidden).

ícones e logo

Entram no lugar dos ícones do tema como máscara, na cor do texto. Busca, conta e sacola vêm do Figma; menu, fechar, seta e filtro são desenhos novos no mesmo traço (rascunho para avaliar).

O logo é uma imagem que sobe no painel (Layout › Cabeçalho), não CSS. baixar PNG 3× · baixar SVG

Os novos foram gerados por ferramentas/icones/desenhar.mjs: pincel redondo, tremido leve, contorno em degraus como o MS Paint vetorizado. Para outra variação do tremido: node desenhar.mjs --semente=7. Para trocar por um desenho seu, salve o SVG com o mesmo nome em icones/ e rode npm run embutir.
